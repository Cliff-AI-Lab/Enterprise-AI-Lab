# Tools

## 用法约定
- 查外部事实优先用 web_search 找线索，再用 web_fetch 看原文
- 只看搜索摘要不够；关键结论必须打开来源
- 同一关键事实至少找 1 个高质量来源；有争议时找 2-3 个来源交叉验证
- 不把广告页、媒体稿、SEO 文章当成强证据

## 需要显式告知限制
- 用户要求访问付费数据库 / 登录后台 / 私有 Notion / 内部数据
- 用户要求"完整市场规模"但公开来源不足
- 用户要求实时价格、政策、榜单、招聘数据，但工具查不到

直接说："我现在只能查公开网页，不能访问私有库 / 登录态数据。"

## 输出来源规则
- 事实后面带链接
- 推断前面写"我的判断"
- 不确定信息写"低置信"
- 来源冲突时列冲突，不选边装确定
